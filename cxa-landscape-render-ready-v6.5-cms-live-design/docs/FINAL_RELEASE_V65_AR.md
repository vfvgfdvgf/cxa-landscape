# تقرير إصدار نخيل نجد V6.5

هذا الإصدار يعالج مشكلة عدم انعكاس تعديلات أقسام الصفحة الرئيسية، ويكمل ربط محرر Django بالواجهة ويصقل التصميم المتجاوب والأزرار والوسائط.

## إصلاحات لوحة التحكم والرئيسية

- أصبحت الصفحة الرئيسية ديناميكية وتطلب بياناتها بدون تخزين نسخة قديمة، كما يرسل مسار `home` ترويسات تمنع الكاش.
- ترتيب كل قسم المحفوظ في لوحة التحكم يطبق فعليًا داخل الصفحة.
- جميع الحقول المدارة مستخدمة: العنوان الصغير، السطر التعريفي، العنوان، الوصف، النص الإضافي، الزران، صورة أو فيديو القسم وروابط العناصر.
- يبقى القسم الظاهر قابلًا للعرض حتى قبل إضافة عناصر متكررة له؛ لا يختفي العنوان والأزرار بسبب قائمة فارغة.
- الهيرو محمي ليبقى ظاهرًا وفي أول الصفحة.
- تمت إضافة معاينة محتوى داخل المحرر وتنبيه عند وجود تغييرات غير محفوظة.
- تستمر الحماية من تكرار الصورة أو الفيديو نفسه في أكثر من ثلاثة مواضع عبر النموذج والـAPI والواجهة.

## صقل الواجهة

- نظام أزرار رئيسي وثانوي واضح للحالات الفاتحة والداكنة، مع مساحة لمس مناسبة وتركيز لوحة مفاتيح ظاهر.
- عرض تحريري متجاوب لصورة أو فيديو كل قسم مع وصف الوسيط ودرجة التعتيم المدارة.
- معالجة عرض صورة القسم الختامي كخلفية كاملة بدل دخولها في تدفق الصفحة.
- فصل تخطيط عنوان الشريط المتحرك عن العنوان الصغير والأزرار لمنع تعارض شبكة CSS.
- تحسين التفاف نصوص الأزرار وترتيبها على الشاشات الصغيرة، ومنع القص الأفقي في شريط الثقة والمعارض الأفقية.
- إضافة سمات تشخيص للقسم وترتيبه لتسهيل التحقق الآلي بعد النشر.

## الرفع إلى Render

ارفع محتويات المشروع إلى نفس مستودع Git ثم نفّذ **Manual Deploy → Deploy latest commit** للخدمتين إذا لم يبدأ Blueprint النشر تلقائيًا. لا تحتاج تغييرات المحتوى المستقبلية من لوحة التحكم إلى إعادة نشر.

راجع `DEPLOY_RENDER_FINAL_AR.md` لإعداد Blueprint والمتغيرات السرية وCloudinary.
