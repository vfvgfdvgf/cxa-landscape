# كتالوج الوسائط المنظم

تم فحص 33 فيديو MP4 و11 صورة JPG من مجلد واتساب، ثم فصل المواد حسب النوع والجودة. الملفات الأصلية H.264 عمودية، لذلك لم يتم تمديدها لتغطية شاشة عريضة؛ بُني فيديو Hero أفقي من ثلاث لقطات عمودية متجاورة للحفاظ على النسب والجودة.

## فيديوهات الإنتاج المستخدمة

| الناتج | المصادر الأصلية | المقاس/المدة | الاستخدام |
|---|---|---|---|
| `hero-triptych.mp4` | `013` + `037` + `002` | 1280×720 / 12ث | Hero سطح المكتب |
| `hero-mobile.mp4` | `037` | 720×1280 / 9ث | Hero الجوال |
| `story-night.mp4` | `004` | 540×960 / 8ث | مشهد نهائي ليلي |
| `story-transplant.mp4` | `026` | 540×960 / 8ث | نقل وزراعة النخيل |
| `story-care.mp4` | `041` | 540×960 / قرابة 8ث | العناية والصيانة |
| `story-finished.mp4` | `036` | 540×960 / 8ث | Hero الصفحات والمشهد الختامي |

كل فيديو بدون صوت، بسرعة 24fps، وترميز H.264 مع `faststart`. تم فك ترميز الملفات الناتجة كاملة بدون أخطاء. بعض النسخ الأصلية كانت تحمل نهاية ملف جزئية؛ تم الاقتصاص وإعادة الترميز قبل الجزء المتأثر.
